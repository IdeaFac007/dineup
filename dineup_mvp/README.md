# DineUp MVP

A frontend-only website prototype for the DineUp restaurant visibility marketplace.

## Included
- Consumer homepage
- Lucknow restaurant leaderboard
- Sponsored labels
- Outbid interaction
- Restaurant promotion CTA
- Basic campaign modal
- Responsive design

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.
